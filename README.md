# VEXTRIVO

VEXTRIVO is an AI website builder landing page and demo experience built as a lightweight static website.

## Run locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Files

- `index.html` — main marketing page
- `styles.css` — responsive styling
- `script.js` — simple interactive behavior

## Project goal

This code gives the repo a polished product landing page for an AI website builder with sections for features, pricing, demo workflow, and FAQ.
